## Компьютер и сервер
- Проект: C:\Users\vsegd\Documents\DOTAMATE — запросить доступ через device_request_folder_access.
- Мост на Windows: задания в "Claude outputs\shell\in\sNN.cmd" (CRLF, без кириллицы в командах), вывод — "Claude outputs\shell\out\sNN.out" (свой вывод перенаправлять в файл с другим именем — sNN.out мост затирает). Мост жив, если обновляется "Claude outputs\shell\alive.txt". Если задание не забирается больше 2 минут — сказать владельцу, не повторять. Имена заданий u4-* заняты процессом «,1».
- SSH только через мост (из Linux-оболочки device_bash ключа нет): node "Claude outputs\shell\sshr.js" - "<команда>" или со скриптом: node "Claude outputs\shell\sshr.js" "Claude outputs\shell\sNN.sh" "bash -s". sshr.js дописывает `SSH_EXIT=…` в конец последней строки — при выгрузке base64 отрезать `sed 's/SSH_EXIT=.*//'`.
- Сервер Hostiman (время MSK): код ~/dotamate-src, сайт ~/www/dotamate.ru, логи посещений ~/logs/dotamate.ru.access.log*, архив эфира ~/dotamate-collector/archive, данные ~/dotamate-data. Crontab править только полным файлом ~/dotamate-collector/crontab.txt.
- **С 10.10.2026 тариф RuBig: RAM 3072 МБ, процессов (NPROC) 115, веб-процессов 30, CPU 70 %, диск 50 000 МБ, время выполнения 400 с** (было RuGold: 1536 МБ, 45, 20, 30 %, 30 000 МБ). Подробно — claude/limit-processov-hostinga.md. Процесс сверх памяти снимается SIGKILL без сообщения; большие файлы читать потоком.
- Ограничения, введённые при старом лимите 45 (09.10 превышение останавливало сайт): тяжёлые задачи по одной (flock ~/dotamate-collector/heavy.lock), у Node UV_THREADPOOL_SIZE=2 и --v8-pool-size=1 (как в crontab), не оставлять фоновые процессы. Снимать по одному и только после наблюдения.
- **Внешние запросы в проверочных скриптах — только с тайм-аутом** и не под heavy.lock (09.10 запрос к OpenDota без тайм-аута держал heavy.lock ~20 мин).
- Перенос файлов из облака на компьютер: каждый раз через новую папку outputs/uN/, после записи сверять md5 (картинки — пиксели).
- Удалять файлы в папке проекта мост не даёт: не создавать временное в корне проекта, только в "Claude outputs".
