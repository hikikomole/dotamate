# Страницы предметов

## Вариант B — шаблон под тип предмета (03.10.2026). Статус: ВЫЛОЖЕНО, версия 30 (03.10.2026 13:14 МСК).
- build-item-pages.js: тип = neutral / cons (расходник) / comp (компонент < 1000 золота) / item (обычный предмет и компонент от 1000, например Blink, Yasha).
  - item: в шапке 3 цифры (доля покупающих, медиана покупки, главная позиция); «Когда покупают» — одна полоса 0–50 мин (q1–q3 + медиана) вместо гистограммы; эффект; сборка; таблица «Соседи по цене» (5 ближайших по цене со статистикой); справа: позиции, герои (покупки/победы), «Кому даёт больше всего» из data/item-impact.json (есть только у части предметов).
  - comp/cons: одна строка «Покупают X% игроков · Y% на старте / медиана»; без колонки справа; у компонента «Во что собирается» первым.
  - neutral: тир, эффект, сетка «Другие нейтральные того же тира»; без цены, статистики и похожих.
  - Примечания и история свёрнуты в <details> (текст остаётся в HTML для SEO).
  - Переменные ITEM_OUT (папка вывода) и ITEM_ONLY (список ключей) — для стенда; без них поведение как раньше.
- css/theme-dark.css: блок itb-* в конце; на телефоне колонка справа уходит вниз.
- Резервные копии: Claude outputs/build-item-pages.before-B.js, theme-dark.before-B.css. Стенд: Claude outputs/stand-b/site.
- Стенд: 1440 и 390 px, Blink, Abyssal Blade, Belt of Strength, Psychic Headband, Tango; ошибок JS нет.
- Сервер после выкладки (8213 матчей, 185 предметов): 253 страницы; 136 с цифрами в шапке и таблицей «Соседи по цене», 45 со строкой-сводкой, 49 нейтральных с сеткой тира, 29 с «Кому даёт больше всего»; theme-dark.css?v=30.
