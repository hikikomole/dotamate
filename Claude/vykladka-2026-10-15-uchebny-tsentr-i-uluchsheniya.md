## Порядок выкладки

1. На ПК: слить PR #2 в `master` (в GitHub — кнопка Merge) и забрать `master` в рабочую папку через GitHub Desktop.
   Рабочее дерево перед этим должно быть чистым.
2. На ПК: `node tools/push-server.js`, без `--with-data`. `data/` — хозяйство сервера.
   Новых файлов в `secrets/` нет.
3. На сервере собрать **все** страницы. После push-server так требует правило v92: push-server
   перезаписывает сгенерированные страницы `deploy/` локальными копиями. В PR лежат страницы центра, собранные из
   устаревших облачных данных, их тоже надо пересобрать.

   **`build-sitemap.js` — после `build-pages.js`.** В старых шаблонах (s147, v92) он стоит раньше, но новый
   sitemap хеширует уже собранные страницы. Если поставить его раньше, `lastmod` разделов опоздает на день.

```sh
cd ~/dotamate-src && export DOTAMATE_SERVER=1 && flock -w 900 ~/dotamate-collector/heavy.lock sh -c '
  node build-hero-pages.js &&
  node build-hero-guides.js &&
  node tools/build-item-stats.js &&
  node build-item-pages.js &&
  node build-guide-pages.js &&
  node build-role-guides.js &&
  node build-glossary-page.js &&
  node build-privacy-page.js &&
  node build-pages.js &&
  node build-sitemap.js &&
  node tools/check-academy-analysis.js &&
  node tools/sync-deploy.js &&
  node tools/deploy-hostiman.js'
```

   Шаги идут строго по одному. Если что-то упало, остальное не запускается, и на сайте остаётся прежняя версия.

4. **Эталон Turbo для разбора.** `posTurbo` и `posSteam` появятся в `data/stats.json` после
   `tools/build-stats.js --source steam`. Это делает ночное обновление: после ручной выкладки отпечаток кода
   совпадёт, и ночь пройдёт как обычно. До ночи разбор Turbo честно пишет, что эталона ещё нет, а рейтинговые
   матчи разбираются по Stratz `positions`. Запускать `build-stats` вручную не обязательно. Если запускать, то под тем
   же `heavy.lock` и до `build-hero-pages.js`: паспорт героя читает тот же `stats.json`.
5. Проверки на сервере и на сайте:
   - `/api/version` — новая версия; `node tools/code-fingerprint.js --check` — совпадает;
   - отдают 200: `/`, `/heroes/`, `/draft/`, `/academy/`, `/academy/match/`, `/academy/practice/`, `/academy/carry/`,
     `/hero/pudge/`, `/hero/vengeful_spirit/`, `/patch/7.41f/`, `/privacy/`, `/js/my-heroes.js`;
   - на `/hero/pudge/` есть `data-myhero` и `hp-tools`, в дереве талантов русские названия
     (`grep -c 'class="hp-tools"' ~/www/dotamate.ru/hero/pudge/index.html` → 1);
   - в `sitemap.xml` есть `/draft/`. В первый запуск у всех адресов сегодняшний `lastmod`: состояния ещё нет, так и задумано. После
     следующей ночи даты должны разойтись. Проверка: `grep -c "<lastmod>$(date +%F)" ~/www/dotamate.ru/sitemap.xml`
     — заметно меньше общего числа адресов;
   - на `/heroes/` блок «Мои герои» показывает подсказку; после отметки героя на его странице — карточку;
   - утром в `~/dotamate-src/logs/daily-*.log` есть шаг «Карта сайта (sitemap)» без ошибки и строка «эталон Турбо …»
     от `build-stats`.
6. IndexNow по новым и изменённым адресам:
   `node tools/indexnow.js /draft/ /academy/ /academy/match/ /academy/practice/ /academy/beginner/ /academy/rank-up/ /academy/carry/ /academy/mid/ /academy/offlane/ /academy/support/ /heroes/ /patch/7.41f/`.
   Страницы героев (127 `/hero/` с русскими талантами) можно отправить отдельным вызовом, списком адресов
