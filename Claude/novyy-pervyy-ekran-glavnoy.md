## Полоса драфта — вид общего инструмента, а не копия

`js/home-draft.js` рисует слоты, вердикт и свой выбор героя; `js/draft-tool.js`
отдаёт мост `window.D2HDraft`: `ready/load/picks/hero/icon/candidates/set/
clear/summary/onChange`. Состояние, история и расчёты общие — герой,
поставленный наверху, стоит и в секции Ranked All Pick.

Грабли, на которые наступили:

- **Окно выбора инструмента живёт внутри `.dt-shell`** и позиционируется
  относительно него. При вызове с первого экрана страница прыгала вниз к
  Ranked All Pick. Поэтому у полосы **своё** окно выбора, а список кандидатов
  берётся у инструмента (`candidates`).
- Полоса стоит у нижнего края первого экрана, поэтому окно **раскрывается
  вверх**, когда снизу меньше своей высоты. Иначе браузер сам утаскивал
  страницу вниз при первом клике по списку.
- Вокруг `set`/`clear` держим позицию прокрутки (`keepScroll`).
- К полному инструменту ведёт только кнопка «Открыть драфт».

## Шапка

Название текстом: `<span class="dm-dot">` + `<span class="dm-word">`.
**Класс `brand-mark` брать нельзя** — он занят в `style.css` под фиолетовый
квадрат 40 px с `!important`; из-за этого в первой версии в шапке висел чужой
значок. Меню прижато к названию (`order` + `gap:26px`, боковые отступы у
ссылок сняты), справа — чип патча. Шрифт Oswald подключается **отдельной
строкой с `display=swap`**: в общей строке стоит `display=optional`, при
котором шрифт заголовков на первом визите просто не применялся бы.

## Страница патча /patch/<версия>/

`tools/fetch-patch-notes.js` → `data/patch-notes.json`. Источник —
`dota2.com/datafeed/patchnotes` в русской локализации Valve, свой пересказ
не нужен. В фиде только идентификаторы, имена подставляем из своих файлов:
герои из `data/heroes.json` + `hero-urls.json`, способности из
`data/ability-index.json` (3044 записи, поле `title`), предметы из
`data/items-ru.json` (ключ — слаг, внутри `id`). Предмет, которого нет в
каталоге (нейтральные), доспрашивается у `datafeed/itemdata` — иначе в
списке был бы «Предмет 1593». Разметку Valve (`<font color>`) снимаем.

Страница собирается `build-pages.js`, пока лежит `data/patch-notes.json`.
У 7.41f: 52 карточки, 35 ссылок на героев, 16 на предметы. Чип в шапке
ведёт на неё **только если версия чипа совпадает с версией собранной
страницы**, иначе остаётся меткой.

Порядок обновления при новом патче:
`node tools/fetch-home-meta.js` → `node tools/fetch-patch-notes.js` →
`node build-pages.js` → `node build-sitemap.js` → `node tools/sync-deploy.js`
→ из `deploy/`: `set -a && . ../.env && set +a && npx wrangler deploy`.
