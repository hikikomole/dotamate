## Как устроено
- `tools/collect-meta-matches.js`: Stratz `match(id)` по одному (пакетный `matches(ids)` → «User is not an admin»). Кандидаты — `data/public-matches`, ranked AP ≥ 20 мин, окно 5 дней: сначала последние сутки, потом остальное вперемешку. В Stratz есть ~25–30% матчей нашего ранга. Два потока, пауза 700 мс; при трёх потоках и после ~1300 запросов подряд Stratz отвечает 429 — сборщик ждёт. Сырьё `data/meta-matches/` (в .gitignore и SKIP_DIRS sync-deploy), `_tried.json`.
- `Собрать META.cmd` (CRLF, без BOM): сбор до 3000 запросов + `build-meta.js`.
- `tools/build-meta.js` → `data/meta-escape.json` (до 1500 сборок, ~350 КБ) + `data/meta-match/<id>.json`. Оценка своя: Σ −ln((c−0,5)/n) по разным не-расходникам финального инвентаря, база — герой+позиция (leave-one-out), при n<30 база по герою целиком, помечается «*». Нишевые: ≤20% матчей героя на позиции, ≥10 игр, >50% побед, сортировка по Уилсону. Прогноз драфта на странице матча — формула инструмента драфта (our-matrix + alpha калибровки).
- `js/meta.js`, `css/meta.css` (пространство mx-/mm-), секции `meta`, `metaMatch` в `page-sections.html`. Общий список с фильтрами стоит первым, прокручивается в своей области, подгрузка по 24 через IntersectionObserver.
- `build-pages.js`: NAV «Игра» → «META», страницы `/meta/` и `/meta/match/` (поле `crumb`, `noSitemap`); у `/game/` `crumb: 'Игра'` (иначе крошка показывала «Патч»). Карточка META на главной вместо «Мини-игры». «Игра» — чип-ссылка в /guides/. Шапка заменена в 7 сборщиках.
