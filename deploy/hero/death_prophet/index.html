На 10, 15, 20 и 25 уровне выбирают один талант из двух. Берут — доля игроков, выбравших талант, Побед — винрейт с ним. Рамка «чаще берут» — выбор большинства, зелёная «выше винрейт» — вариант, который выигрывает чаще.

Способности

Crypt Swarm

По целиВ точку

Посылает вперёд стаю крылатых тварей, наносящих урон врагам на своём пути.

Silence

По площадиВ точку

Выпускает снаряд, который запрещает врагам в указанной области применять способности.

Spirit Siphon

По цели

Герой создаёт мистическую связь с вражеским существом, передавая его здоровье себе.

Witchcraft

ПассивнаяСкрытая

Полученный опыт расширяет оккультные знания героя: с каждым уровнем его скорость передвижения увеличивается, а перезарядки заклинаний уменьшаются.

Exorcism

Без цели

Герой выпускает злых духов, вытягивающих здоровье из вражеских существ и построек поблизости. После каждой атаки дух должен вернуться к владельцу, прежде чем атаковать вновь. Через 40 сек. духи возвращаются окончательно, исцеляя владельца…
