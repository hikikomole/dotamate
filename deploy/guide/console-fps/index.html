Консоль в Dota 2: как включить, параметры запуска и как поднять FPS

Как открыть консоль в Dota 2, какие параметры запуска реально поддерживает игра, как показать FPS и пинг и какие настройки поднимают частоту кадров. Проверено по файлам игры.

Коротко

Чтобы открыть консоль, включи в настройках Dota 2 пункт «Включить консоль» или добавь параметр запуска -console. По умолчанию консоль открывается клавишей \ (обратная косая черта). Показать FPS и пинг можно пунктом «Отображать информацию о сети» или командой cl_showfps 1.

Как включить консоль

Самый простой способ — пункт «Включить консоль» в настройках игры. После этого консоль открывается клавишей \ (обратная косая черта), так она назначена в стандартной раскладке.

Второй способ — параметр запуска -console. Если он задан (или задан -dev), игра не смотрит на пункт в настройках.

Клавишу можно поменять в настройках горячих клавиш: там есть действие «Консоль». Сама игра подписывает его как функцию для опытных пользователей.

Как задать параметры запуска

Параметры запуска задаются в Steam: Библиотека → правой кнопкой по Dota 2 → Свойства → Общие → поле «Параметры запуска». Несколько параметров пишутся через пробел, например: -console +fps_max 240.

Параметры запуска, которые поддерживает игра

В таблице только параметры, которые упоминаются в самих настройках Dota 2. Списки с десятками «секретных» параметров на других сайтах часто содержат команды из старых версий игры, которые больше ничего не делают.

ПараметрЧто делает
-consoleВключает консоль независимо от пункта в настройках.
+fps_max 240Ограничение кадров в секунду в матче. Нужно, если нужное значение выходит за пределы ползунка в настройках.
+ui_fps_max 60То же для главного меню.
-dx11Запуск на Direct3D 11 вместо API, выбранного в настройках.
-vulkanЗапуск на Vulkan вместо API, выбранного в настройках.
-safe_modeВозвращает стандартный API рендеринга, если после смены API игра перестала нормально запускаться.

Проверено по текстам настроек Dota 2 (русская локализация игры), сентябрь 2026.

Команды для консоли

Команды вводятся в открытую консоль во время игры. Каждая из них есть в текущей версии Dota 2. Если команда не срабатывает, значит в обычных матчах Valve её закрыла.

КомандаЧто делает
cl_showfps 1Показывает FPS в углу экрана. cl_showfps 0 — скрывает.
fps_max 0Снимает ограничение FPS. Любое другое число — лимит кадров в секунду.
cl_globallight_shadow_mode 0Упрощает динамические тени от основного освещения, это снижает нагрузку на видеокарту.
r_ssao 0Отключает затенение фонового освещения (SSAO) — мягкие тени у предметов и стен.
gpu_level 0Минимальный уровень качества для видеокарты (по умолчанию высокий).
cpu_level 0Минимальный уровень нагрузки на процессор (по умолчанию высокий).
dota_selection_groups 0Не объединяет призванных существ с героем в одну группу выделения. Полезно для героев с юнитами, например Beastmaster.
dota_minimap_misclick_time 0Убирает задержку, с которой миникарта реагирует на промах по ней.
dota_force_right_click_attack 1Правый клик по союзному юниту атакует его (денай), а не ведёт следом за ним.
dota_health_hurt_decay_time_max 0Убирает задержку, с которой полоска здоровья показывает полученный урон.
dota_screen_shake 0Отключает тряску экрана от способностей.
cl_updaterate 30Сколько обновлений в секунду клиент запрашивает у сервера.
cl_interp_ratio 1Величина сглаживания движения между обновлениями сервера.
rate 80000Скорость приёма данных от сервера в байтах в секунду.

Наличие каждой команды проверено по файлам игры, сентябрь 2026.

Чтобы не вводить команды после каждого запуска, их можно записать в файл autoexec.cfg в папке dota 2 beta/game/dota/cfg: по одной команде в строке. Игра выполняет этот файл при старте.

Параметры из старых гайдов, которые не работают

В популярных списках параметров много команд из старой версии Dota 2 и других игр Valve. Мы сверили их с файлами текущей версии.

ПараметрПочему не стоит добавлять
-glВ игре больше нет рендера OpenGL для Windows: доступны только Direct3D 11 и Vulkan.
-nod3d9exОтносится к DirectX 9, который игра больше не поддерживает.
cl_interp 0.033Команда только для чтения: игра сама пишет, что её значение нельзя поменять, и просит убрать её из скрипта.
map dotaЭто не предзагрузка, а запуск локальной карты. Для поиска игры она ничего не ускоряет.
-map_enable_background_maps 0Такого параметра в текущей версии игры нет.
-novid, -high, -prewarm, -nojoy, -noaafonts, -threadsПришли из старой версии Dota 2 и других игр Valve. В файлах текущей версии подтверждения, что они на что-то влияют, нет. Добавлять их можно, но ощутимого эффекта ждать не стоит.

Как показать FPS и пинг

В настройках есть пункт «Отображать информацию о сети». Он показывает в матче частоту кадров, задержку и потерю пакетов.

Через консоль то же можно сделать командой cl_showfps. Значение 1 показывает текущий FPS, 2 — сглаженный.

Как поднять FPS

Все советы ниже взяты из подсказок самой игры к настройкам:

  • Снизь «Качество обработки экрана» ниже 100 %. По словам игры, низкие значения поднимают частоту кадров ценой качества картинки.
  • Включи FidelityFX Super Resolution, если качество обработки ниже 100 %. Это апскейлинг, который возвращает чёткость. Работает только на Direct3D 11 или Vulkan и при включённом «Сглаживании».
  • Включи «Расчёт шейдеров» (только Vulkan и DirectX 11). Игра пишет, что на большинстве компьютеров это повышает производительность.
  • Проверь режим питания Windows. В режиме энергосбережения игра сама предупреждает, что частота кадров будет ниже.
  • Отключи «DVR для игр» (запись игр Xbox). Игра предупреждает, что эта функция может снижать или ограничивать частоту кадров и вызывать зависания.
  • NVIDIA Reflex и AMD Anti-Lag 2.0 снижают задержку ввода, но в режиме максимального снижения задержки немного уменьшают частоту кадров.

Как забиндить клавиши

Большинство действий назначается без консоли, в настройках горячих клавиш: способности, предметы, курьер, камера, консоль. Нажми на действие и затем на нужную клавишу.

Откуда эта информация

Названия настроек, параметры запуска и подсказки взяты из файлов Dota 2 (русская локализация и стандартная раскладка клавиш), описание cl_showfps — из самой игры. Статья проверена на версии игры сентября 2026 года.

Частые вопросы

Как открыть консоль в Dota 2?

Включи в настройках пункт «Включить консоль» или добавь параметр запуска -console, затем нажми клавишу \ (обратная косая черта).

Как посмотреть FPS в Dota 2?

Включи в настройках «Отображать информацию о сети» или введи в консоли cl_showfps 1.

Как убрать ограничение FPS?

В настройках есть «Максимальное число кадров в секунду». Если нужного значения нет на ползунке, задай параметр запуска +fps_max, например +fps_max 240.

Какие команды поднимают FPS?

В консоли: cl_globallight_shadow_mode 0 (упрощает тени), r_ssao 0 (отключает SSAO), gpu_level 0 и cpu_level 0 (минимальные уровни качества). Плюс настройки: «Качество обработки экрана» ниже 100 % с FSR и «Расчёт шейдеров».

Игра не запускается после смены API рендеринга, что делать?

Добавь параметр запуска -safe_mode: он вернёт стандартный API.
