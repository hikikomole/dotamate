# План архива завершённых матчей

## Цель и границы

Строим локально проверяемый архив уже сыгранных матчей Dota 2. Каждая запись проходит получение реплея Valve, разбор, нормализацию и сохранение; затем матч доступен на странице просмотра и может учитываться в отдельной статистике матчей, собранных нашим парсером. Это просмотр реплеев после игры, без live-обновления и без обещания, что матч появится сразу после завершения.

## Этапы

1. **Зафиксировать доступные данные и формат матча.** Описать схему завершённого матча: метаданные, результат и состав команд, временные координаты, минутные срезы показателей, журнал событий, драки, объекты и финальную статистику игрока. Отмечать точность и происхождение каждого поля.
2. **Проверить извлечение на реальном реплее.** Использовать матч `9017989603`, проверить диапазоны времени, соответствие слотам игроков, координатам, событиям и минутным рядам. Наблюдения пока считать проверкой прототипа, а не гарантией для всех версий реплея.
3. **Сделать нормализатор и локальный формат хранения.** Отделить большой/временный вывод анализатора от компактных данных сайта. Повторная обработка того же ID обновляет запись, не создавая дубликат; ошибки и стадия обработки фиксируются отдельно.
4. **Собрать локальный архив и просмотр матча.** Сделать индекс обработанных матчей и страницу матча с воспроизведением движения, временной шкалой событий, фильтрами героев/слоёв карты, минутной статистикой выбранного героя и итоговой таблицей.
5. **Подключить очередь обработки исторических реплеев.** Обрабатывать известные ID по одному или партиями, с ограничениями Valve, повторами, журналом статусов и возможностью возобновить после ошибки. Автоматически искать ещё не завершённые матчи не требуется; порядок пополнения архива определяется доступным источником ID и доступностью реплея.
6. **Добавить раздел общей статистики архива.** Считать число обработанных матчей, результаты и агрегаты героев из нормализованных записей. Явно обозначить источник и охват, не смешивать эти показатели с текущей выборкой публичных матчей сайта.
7. **Проверить на серии реплеев.** Сравнить несколько матчей, неполные и старые реплеи, повторы, повреждённые ответы, производительность и объём хранения. После локальной приёмки отдельно решать вопрос о production-развёртывании.

## Текущий старт

Fixture: `9017989603`. Уже есть полный результат Gem parser с координатами `[tick, x, y]`, минутными рядами экономики/опыта, combat log, событиями объектов и командными драками. Первый выполняемый шаг — превратить fixture в безопасный для просмотра нормализованный файл архива и связать его с локальным интерфейсом. В этой версии имена и Steam ID игроков не публикуются.
