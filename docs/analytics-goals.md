# Цели Яндекс Метрики

Счётчик: `112755250`. Создать цели типа «JavaScript-событие».

| Идентификатор | Где | Условие |
| --- | --- | --- |
| `match_analysis_submit` | `/academy/match/` | Корректный Steam ID или заполненная ручная форма. |
| `site_search` | Поиск сайта и гайдов | Непустой запрос отправлен или выбран результат. |
| `app_download` | Ссылка загрузки приложения | Клик по ссылке `.exe`, `.msi`, `.dmg`, `.appx` или `.zip`, если она есть. |
| `theme_toggle` | Кнопка темы | Клик. |
| `guide_internal_link` | `/guide/` | Клик по ссылке на `/game/` или `/items/`. |

Вызовы защищены проверкой наличия `ym`.
